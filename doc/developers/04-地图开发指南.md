## 1. 地图创建工具链概览

地图创建分四个脚本，串成一条流水线：

```
第 0 步（可选）        第 1 步（可选）         第 2 步              第 3 步
png_to_json.py   或   walls_to_json.py   →   map_wall_editor.py →  json_to_map.py
PNG → JSON            walls_xxx.py → JSON    JSON 可视化编辑       JSON → 地图代码
```

| 步骤 | 工具 | 输入 | 输出 |
|------|------|------|------|
| 0（可选） | `png_to_json.py` | 黑白 PNG 地图 | 编辑器 JSON（墙体） |
| 1（可选） | `walls_to_json.py` | 已有 `walls_xxx.py` | 编辑器 JSON（墙体） |
| 2 | `map_wall_editor.py` | 编辑器 JSON | 编辑后的编辑器 JSON |
| 3 | `json_to_map.py` | 编辑器 JSON | `map_<name>.py` + `walls_<name>.py` |

编辑器是整条流水线的中枢：所有导入的墙体都先转成**编辑器 JSON**，在 GUI 里可视化增删改，最后统一由 `json_to_map.py` 生成可运行的地图代码。

工具全部位于 `src/swarm_rescue/tools/`，无额外第三方依赖（编辑器可选依赖 PySide6，缺失时自动回退 Tkinter）。

## 2. 从 PNG 提取墙体：png_to_json

将手绘的或参考的 PNG 地图（**黑色=墙体，白色=背景**）矢量化，输出编辑器可识别的 JSON。

```bash
.venv/bin/python -m swarm_rescue.tools.png_to_json <输入PNG> <输出JSON> [--export-png]
```

参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `input_png` | 是 | 输入 PNG 路径 |
| `output_json` | 是 | 输出 JSON 路径（编辑器格式） |
| `--export-png` | 否 | 同时导出识别结果的渲染 PNG（与输出 JSON 同目录同名） |

算法采用两阶段：

- **实心矩形块** → `rect_wall`（按连通域矩形度与厚度判断）
- **线条墙体** → `line_wall`（骨架化 + 概率霍夫变换 `HoughLinesP`）

输出 JSON 可直接在编辑器中加载精修。矢量化精度有限，**导入后必须在编辑器中检查修正**。常见问题：边角线段断裂、细长条被误识别为矩形、文字/标注被误识别为墙体。线条清晰、粗细均匀、对比度高的 PNG 效果最好。

## 3. 从现有墙体代码转换：walls_to_json

将已有的 `walls_xxx.py`（Python 墙体定义）转成编辑器 JSON，用于在编辑器中继续修改。

```bash
.venv/bin/python -m swarm_rescue.tools.walls_to_json <walls文件> <输出JSON> [--width 宽度] [--height 高度]
```

参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `walls文件` | 是 | `walls_xxx.py` 路径，如 `src/swarm_rescue/maps/walls_04.py` |
| `输出JSON` | 是 | 输出 JSON 路径 |
| `--width` | 否 | 地图宽度（像素），默认 1113 |
| `--height` | 否 | 地图高度（像素），默认 750 |

> **重要**：`--width`/`--height` 必须与对应 `map_xxx.py` 中的 `self._size_area` 一致，否则坐标会错位。

转换通过 **AST 静态解析**完成，不需要导入模块，也不依赖运行时库：

| 源文件类型 | JSON 类型 |
|-----------|-----------|
| `NormalWall` | `line_wall` |
| `NormalBox` | `rect_wall` |

世界坐标会换算成画布像素坐标（y 轴翻转）。无法静态解析的表达式坐标（变量/函数调用）会计入 skipped 并在终端提示，需在编辑器中手动补充。

示例：

```bash
# walls_04.py 对应的地图尺寸是 1660×1122
.venv/bin/python -m swarm_rescue.tools.walls_to_json \
    src/swarm_rescue/maps/walls_04.py \
    /tmp/medium_edited.json \
    --width 1660 --height 1122
```

输出：

```
转换完成！
  输入：src/swarm_rescue/maps/walls_04.py
  输出：/tmp/medium_edited.json
  地图尺寸：1660 x 1122
  线段墙：68 条
  方块墙：3 个
  元素总数：71
```

## 4. 使用地图编辑器 (GUI)

### 4.1 启动

```bash
.venv/bin/python -m swarm_rescue.tools.map_wall_editor
```

编辑器优先使用 **PySide6**（Qt）；未安装时自动回退到 **Tkinter**，两个版本功能一致。只处理 JSON 格式地图；可将 JSON 渲染导出为 PNG 便于查看。

### 4.2 界面布局

- **第一行工具栏**：工具（单选）+ 文件操作 + 画布尺寸
- **第二行属性面板**：选中元素后显示坐标输入
- **状态栏**：实时提示当前工具、操作结果
- **画布**：白底，支持虚线预览

### 4.3 工具与文件操作

| 工具/按钮 | 说明 |
|-----------|------|
| **选择** | 左键点选元素；右键删除点击处的墙体（线段墙有 8px 命中容差） |
| **线段墙 (6px)** | 点击两点确定一条线段墙，线宽 6px |
| **矩形墙** | 点击两个对角点确定实心矩形墙 |
| **起点区域** | 标记无人机出生区域（全局唯一，重复绘制会替换旧区域；只取中心点坐标，不生成实体区域对象） |
| **DisposalCenter** | 标记炸弹处置中心（全局唯一，重复绘制会替换旧区域） |
| **保存 JSON** | 导出当前画布为编辑器 JSON |
| **加载 JSON** | 载入 JSON；画布自动适配 JSON 中记录的尺寸，窗口同步缩放 |
| **导出 PNG** | 将墙体渲染为 PNG 图片（白底黑墙，起点区域/处置中心带彩色标记） |
| **画布宽 / 高 / 应用尺寸** | 修改画布尺寸（范围 100 ~ 10000），以**左上角为锚点**；尺寸变小时自动裁剪超出边界的元素 |

所有绘制均为"两次点击"：第一点记录起点，移动鼠标显示虚线预览，第二点完成。

### 4.4 属性面板（精确编辑）

选中元素后在第二行属性面板直接输入像素坐标，**回车应用**：

| 元素 | 属性 |
|------|------|
| 线段墙 | `x1, y1, x2, y2` + 长度（只读显示） |
| 矩形类（矩形墙 / 起点区域 / DisposalCenter） | `x1, y1, x2, y2`（两个对角点坐标） |
| 删除选中 | 删除当前选中元素 |

矩形坐标修改后自动归一化，保证 `top_left <= bottom_right`。坐标值以左上角为原点、x 向右、y 向下（像素坐标）。

### 4.5 画布尺寸调整

- 加载 JSON 时画布自动取 JSON 中记录的尺寸
- 手动改右上角"宽/高"后点"应用尺寸"即调整，以左上角 (0,0) 为锚，只改变右/下边界
- 尺寸变大：元素位置不变，右/下方留白
- 尺寸变小：超界元素被裁剪（线段截断到边界、矩形截断到边界、完全在外部者删除，退化为点/零面积者丢弃）

> 新建空白地图时，可先把画布调到目标尺寸再开始绘制。

### 4.6 编辑流程示例

1. 「加载 JSON」打开上一步生成的 JSON（如来自 `walls_to_json` / `png_to_json`，或文件夹里现成的地图 JSON）
2. 用「线段墙/矩形墙」补墙，右键删除多余墙
3. 用「起点区域」「DisposalCenter」标记出生区和处置中心
4. 「选择」工具点选元素 → 属性面板精确改坐标 → 回车
5. 「保存 JSON」导出

### 4.7 JSON 结构

```json
{
  "version": 1,
  "canvas": {"width": 1250, "height": 800, "background": "white"},
  "elements": [
    {
      "id": 1,
      "type": "line_wall",
      "points": [[0, 3], [1247, 3]],
      "thickness": 6,
      "color": "#000000"
    },
    {
      "id": 2,
      "type": "rect_wall",
      "top_left": [980, 680],
      "bottom_right": [1020, 720],
      "color": "#000000"
    },
    {
      "id": 3,
      "type": "start_area",
      "top_left": [7, 211],
      "bottom_right": [233, 394],
      "color": "#1E90FF"
    },
    {
      "id": 4,
      "type": "disposal_center",
      "top_left": [7, 7],
      "bottom_right": [233, 190],
      "color": "#228B22"
    }
  ]

```

> 上面的 `line_wall` / `start_area` / `disposal_center` 取自 `map_data/map_01.json`，`rect_wall` 取自 `map_data/map_02.json`。五张地图的编辑器源文件全部在 `map_data/map_01.json` … `map_05.json`（对应 PNG 同名），可用来核对坐标。

元素类型：

| 类型 | 字段 | 说明 |
|------|------|------|
| `line_wall` | `points` + `thickness` | 线段墙 |
| `rect_wall` | `top_left` + `bottom_right` | 矩形障碍物 |
| `start_area` | `top_left` + `bottom_right` | 起点区域（全局唯一） |
| `disposal_center` | `top_left` + `bottom_right` | 处置中心（全局唯一） |

## 5. JSON 转地图代码：json_to_map

将编辑器 JSON 转为 Swarm-Rescue 可直接运行的地图文件。

```bash
.venv/bin/python -m swarm_rescue.tools.json_to_map <输入JSON> --name <地图名> [--maps-dir <目录>]
```

参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `input_json` | 是 | 编辑器 JSON 路径 |
| `--name` | 是 | 地图名，如 `my_new_map`，自动规范化为合法模块名 |
| `--maps-dir` | 否 | 输出目录，默认 `src/swarm_rescue/maps` |

`--name` 决定命名：类名 `MapMyNewMap`（PascalCase + `Map` 前缀）、模块 `map_my_new_map.py` / `walls_my_new_map.py`。

**生成文件**（仅两个）：

| 文件 | 说明 |
|------|------|
| `map_<name>.py` | 完整地图类，继承 `MapAbstract`，自带 `main()` 可独立预览 |
| `walls_<name>.py` | 墙体辅助函数 `add_walls()` / `add_boxes()` |

示例：

```bash
.venv/bin/python -m swarm_rescue.tools.json_to_map \
    /tmp/medium_edited.json \
    --name my_new_map \
    --maps-dir src/swarm_rescue/maps/
```

输出：

```json
{
  "map_py": "src/swarm_rescue/maps/map_my_new_map.py",
  "walls_py": "src/swarm_rescue/maps/walls_my_new_map.py"
}
```

### 生成的地图类默认设置

- `_max_timestep_limit = 7200`，`_max_walltime_limit = 1440` 秒
- `number_drones` 参数透传：`self._number_drones = self._number_drones_override if ... else 10`
- 起点区域取**矩形中心点世界坐标**存入 `_start_area_drones`，无人机以 40px 间距在中心点附近排成方阵出生
- DisposalCenter 按其矩形尺寸与中心点实例化 `DisposalCenter` 加入 playground
- `_bombs_pos` / `_bombs_path` 为空（炸弹位置需后续手动添加，见第 9 节）

**元素缺失时的默认值**：JSON 中没有起点区域时，默认落在左下角附近（`margin = max(60, min(w,h)//8)`）；没有处置中心时默认在右下角（尺寸 `min(160, w//7) × min(120, h//6)`）。

### 生成后的手动调整

生成的地图类可直接运行，以下内容按需手动补：

- **特殊区域**（NoComZone / NoGpsZone / KillZone）：编辑器不支持绘制，需手动在 map 文件里加（见第 8 节）
- `_max_timestep_limit` / `_max_walltime_limit`
- `_bombs_pos` 与 `_bombs_path`（炸弹布局）

## 6. 手写地图类

需要精细控制时也可直接手写地图类和墙体模块（仓库当前的 `map_01.py`–`map_05.py` 与对应 `walls_*.py` 均由 `json_to_map.py` 生成，可作结构参考）。

### 6.1 坐标系

**世界坐标系**（物理模拟用）：

- 原点 `(0, 0)` 位于地图**中心**
- X 正方向为右，Y 正方向为上
- `_size_area = (width, height)` 表示世界范围 `(-width/2, -height/2)` 到 `(width/2, height/2)`

**像素坐标系**（编辑器用）：

- 原点位于画布**左上角**
- X 正方向为右，Y 正方向为下

**坐标换算**（`json_to_map.py` 实现）：

```python
def _point_to_world(x: int, y: int, width: int, height: int) -> Tuple[int, int]:
    xw = int(round(x - width / 2))          # 水平平移半个宽度
    yw = int(round(-y + height / 2))         # 垂直翻转 + 平移半个高度
    return xw, yw
```

例如画布 1113×750 中，像素 `(557, 375)`（画布中心）→ 世界 `(0, 0)`；像素 `(0, 0)`（左上角）→ 世界 `(-556, 375)`。

### 6.2 地图类必需字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `_size_area` | `(int, int)` | 世界尺寸 |
| `_max_timestep_limit` | `int` | 最大仿真步数 |
| `_max_walltime_limit` | `int` | 最大墙上时间（秒），超时自动结束 |
| `_start_area_drones` | `(x, y)` | 无人机出生区域**中心点**（世界坐标） |
| `_disposal_center` | `DisposalCenter` | 拆弹中心对象 |
| `_disposal_center_pos` | `((x, y), angle)` | 拆弹中心位置与角度 |
| `_bombs_pos` | `List[(x, y)]` | 炸弹初始位置列表（世界坐标） |
| `_bombs_path` | `List[List[(x, y)]]` | 炸弹巡逻路径 |
| `_number_bombs` | `int` | 炸弹数量（`len(self._bombs_pos)`） |
| `_bombs` | `List[Bomb]` | 炸弹对象列表（`__init__` 中创建） |
| `_number_drones` | `int` | 无人机数量 |
| `_drones_pos` | `List[((x, y), angle)]` | 无人机出生位置列表 |
| `_drones` | `List[DroneAbstract]` | 无人机实例列表 |
| `_playground` | `ClosedPlayground` | 物理世界实例 |

### 6.3 巡逻路径 (_bombs_path)

`_bombs_path` 中每个元素是一个炸弹的路径点列表，炸弹沿路径点**往复巡逻**：

```python
self._bombs_path = [
    [],                                                     # 炸弹 0：静止
    [(-100.0, 50.0), (100.0, -50.0)],                       # 炸弹 1：两点间往复
    [(200.0, 100.0), (250.0, 200.0), (150.0, 200.0)],       # 炸弹 2：三角形巡逻
]
```

创建炸弹时需调用 `add_pose_to_path()` 添加初始位置和所有路径点（见 6.4 模板）。

### 6.4 构造函数签名

```python
class MapMyNewMap(MapAbstract):
    def __init__(
        self,
        drone_type: Type[DroneAbstract],          # 参赛队伍提供的无人机类
        zones_config: ZonesConfig = (),           # 禁能区域配置
        number_drones: int | None = None,         # 可选：覆盖无人机数量
    ):
        super().__init__(drone_type, zones_config, number_drones=number_drones)
```

Launcher 通过 `globals().get(eval_config.map_name)` 获取类后以关键字参数构造（见 `launcher.py`）。

### 6.5 地图类模板（出生点 + 区域写法）

```python
import math
import random
from typing import List, Type, Tuple

import numpy as np

from swarm_rescue.simulation.drone.drone_abstract import DroneAbstract
from swarm_rescue.simulation.drone.drone_motionless import DroneMotionless
from swarm_rescue.simulation.elements.disposal_center import DisposalCenter
from swarm_rescue.simulation.elements.bomb import Bomb
from swarm_rescue.simulation.gui_map.closed_playground import ClosedPlayground
from swarm_rescue.simulation.gui_map.map_abstract import MapAbstract
from swarm_rescue.simulation.reporting.evaluation import ZonesConfig
from swarm_rescue.simulation.utils.misc_data import MiscData
from swarm_rescue.simulation.utils.pose import Pose

from swarm_rescue.maps.walls_mynewmap import add_walls, add_boxes


class MapMyNewMap(MapAbstract):

    def __init__(
        self,
        drone_type: Type[DroneAbstract],
        zones_config: ZonesConfig = (),
        number_drones: int | None = None,
    ):
        super().__init__(drone_type, zones_config, number_drones=number_drones)

        # === 地图参数 ===
        self._max_timestep_limit = 7200
        self._max_walltime_limit = 1440          # 秒
        self._size_area = (1000, 800)

        # === 处置中心与出生区 ===
        self._disposal_center = DisposalCenter(size=(120, 200))
        self._disposal_center_pos = ((400, -300), 0)
        self._start_area_drones = (-350, -300)   # 出生区中心点（世界坐标）

        # === 炸弹 ===
        self._bombs_pos = [(0, 100), (50, -50), (-100, 0)]
        self._bombs_path = [
            [],
            [(-100.0, 100.0), (200.0, 50.0)],
            [],
        ]
        self._number_bombs = len(self._bombs_pos)
        self._bombs: List[Bomb] = []

        # === 无人机出生（围绕中心点排方阵） ===
        self._number_drones = (
            self._number_drones_override
            if self._number_drones_override is not None
            else 10
        )
        start = self._start_area_drones
        nb_per_side = math.ceil(math.sqrt(self._number_drones))
        dist = 40.0
        sx = start[0] - (nb_per_side - 1) * 0.5 * dist
        sy = start[1] - (nb_per_side - 1) * 0.5 * dist
        self._drones_pos = []
        for i in range(self._number_drones):
            x = sx + (float(i) % nb_per_side) * dist
            y = sy + math.floor(float(i) / nb_per_side) * dist
            self._drones_pos.append(((x, y), random.uniform(-math.pi, math.pi)))
        self._drones: List[DroneAbstract] = []

        # === 构建物理世界 ===
        self._playground = ClosedPlayground(size=self._size_area)
        self._playground.add(self._disposal_center, self._disposal_center_pos)

        add_walls(self._playground)
        add_boxes(self._playground)
        self._explored_map.initialize_walls(self._playground)

        # === 创建炸弹 ===
        for i in range(self._number_bombs):
            bomb = Bomb(disposal_center=self._disposal_center)
            self._bombs.append(bomb)
            pos = (self._bombs_pos[i], 0)
            self._playground.add(bomb, pos)
            bomb.add_pose_to_path(Pose(np.array(pos[0])))
            if i < len(self._bombs_path):
                for pt in self._bombs_path[i]:
                    bomb.add_pose_to_path(Pose(np.array(list(pt))))

        # === 创建无人机 ===
        misc_data = MiscData(
            size_area=self._size_area,
            number_drones=self._number_drones,
            max_timestep_limit=self._max_timestep_limit,
            max_walltime_limit=self._max_walltime_limit,
        )
        for i in range(self._number_drones):
            drone = drone_type(identifier=i, misc_data=misc_data)
            self._drones.append(drone)
            self._playground.add(drone, self._drones_pos[i])
```

### 6.6 墙体模块模板

```python
"""
墙体辅助模块，为 MapMyNewMap 提供 add_walls 和 add_boxes 函数。
"""
from swarm_rescue.simulation.elements.normal_wall import NormalWall, NormalBox


def add_boxes(playground):
    """添加矩形障碍物（NormalBox）。"""
    box = NormalBox(up_left_point=(32, 35), width=298, height=188)
    playground.add(box, box.wall_coordinates)


def add_walls(playground):
    """添加线段墙体（NormalWall）。"""
    wall = NormalWall(pos_start=(-402, 242), pos_end=(-104, 242))
    playground.add(wall, wall.wall_coordinates)
```

坐标均为世界坐标：

- `NormalBox`：`up_left_point`（左上角世界坐标）+ `width` + `height`
- `NormalWall`：`pos_start` + `pos_end`（线段两端世界坐标）

## 8. zones_config 与禁能区域

### 8.1 ZoneType 枚举

定义在 `src/swarm_rescue/simulation/elements/sensor_disablers.py`：

| 枚举值 | 对应区域类 | 效果 |
|--------|-----------|------|
| `NO_COM_ZONE` | `NoComZone` | 通信器禁用 |
| `NO_GPS_ZONE` | `NoGpsZone` | GPS 与罗盘失效 |
| `KILL_ZONE` | `KillZone` | 所有设备禁用（无人机被摧毁） |

### 8.2 在地图类中定义

在地图 `__init__` 中定义区域对象与位置，只在 `_zones_config` 包含对应类型时才加入 `_playground`：

```python
self._no_com_zone = NoComZone(size=(402, 742))
self._no_com_zone_pos = ((-328, 72), 0)
self._no_gps_zone = NoGpsZone(size=(574, 393))
self._no_gps_zone_pos = ((-538, 42), 0)
self._kill_zone = KillZone(size=(89, 77))
self._kill_zone_pos = ((-576, 112), 0)

# playground 构建后按需加入
if ZoneType.NO_COM_ZONE in self._zones_config:
    self._playground.add(self._no_com_zone, self._no_com_zone_pos)
if ZoneType.NO_GPS_ZONE in self._zones_config:
    self._playground.add(self._no_gps_zone, self._no_gps_zone_pos)
if ZoneType.KILL_ZONE in self._zones_config:
    self._playground.add(self._kill_zone, self._kill_zone_pos)
```

一张地图可定义多个同类区域（在同一 `if ZoneType.XXX in self._zones_config:` 块中 `add` 多次即可；仓库当前五张地图未定义任何区域）。

### 8.3 在 YAML 中配置

```yaml
zones_config: []
zones_config: [NO_COM_ZONE]
zones_config: [NO_COM_ZONE, NO_GPS_ZONE]
zones_config: [KILL_ZONE]
```

同一张地图可在评估计划中以不同 `zones_config` 多次引用以测试难度梯度。

## 9. 炸弹：手动位置与炸弹编辑器

### 9.1 手写 _bombs_pos / _bombs_path

地图类中直接维护世界坐标：

```python
self._bombs_pos = [(-100, 200), (50, -150), (0, 0)]
self._bombs_path = [
    [],                                # 炸弹 0：静止
    [(-100, 200), (50, -150)],         # 炸弹 1：两点间往复
    [],                                # 炸弹 2：静止
]
```

`len(_bombs_path) < len(_bombs_pos)` 时，多余炸弹视为静止。每颗炸弹需把 `disposal_center` 指向正确处置中心。

### 9.2 使用炸弹编辑器 (bomb_editor)

`bomb_editor.py` 提供独立 GUI，在已有地图上交互式放置炸弹并导出 JSON，无需改地图源码：

```bash
.venv/bin/python -m swarm_rescue.tools.bomb_editor Map01
.venv/bin/python -m swarm_rescue.tools.bomb_editor Map04 -o my_bombs.json
```

| 操作 | 功能 |
|------|------|
| 左键点击 | 在点击位置添加一枚炸弹 |
| 右键点击 | 移除最近的炸弹 |
| J 键 | 导出炸弹为 JSON |
| I 键 | 从 JSON 导入炸弹 |
| K 键 | 清除所有炸弹 |
| Enter | 锁定编辑并开始模拟（DroneMotionless 预览） |
| Q 键 | 退出 |

导出 JSON 格式：

```json
{
  "map_name": "Map01",
  "zones_config": [],
  "bombs": [
    {"x": -220, "y": 80, "theta": 0}
  ]
}
```

兼容 `load_bombs_file()` / `bombs_from_data()`。

### 9.3 使用炸弹 JSON

**方式一：Launcher 手动炸弹编辑**

```bash
.venv/bin/python -m swarm_rescue.launcher \
    --manual-bomb-edit \
    --manual-bombs-in bombs_Map01.json \
    -c config/competition_rescue_eval_plan.yml
```

**方式二：YAML 配置 `bombs_file`**

```yaml
evaluation_plan:
  - map_name: Map01
    bombs_file: bombs_Map01.json
    nb_rounds: 1
    number_drones: 10
    zones_config: []
```

```bash
.venv/bin/python -m swarm_rescue.launcher \
    --bombs-file bombs_Map01.json \
    -c config/custom_eval_plan.yml
```

### 9.4 推荐工作流

1. `walls_to_json` / `png_to_json` + `map_wall_editor` + `json_to_map` 创建地图骨架
2. `bomb_editor` 交互式放置炸弹，导出炸弹 JSON
3. YAML 配置 `bombs_file` 进行蓝队评估
4. 满意后把坐标复制进地图类的 `_bombs_pos`（可选）

### 10.5 常见问题排查

- **地图类找不到**：类名已在 `launcher.py` 导入，且 YAML `map_name` 与类名完全一致
- **墙体未显示**：`walls_xxx.py` 坐标是否在世界范围内
- **炸弹看不见**：确认已 `playground.add(bomb, pos)` 且 `Bomb(disposal_center=...)` 参数正确
- **OpenGL 错误**：需要 OpenGL 4.4+ / GLSL 440；无 GPU 用 `xvfb-run`，或 `ClosedPlayground(..., use_shaders=False)`（性能降低）
